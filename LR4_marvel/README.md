# ЛР 4 — генерация признаков и baseline

Ноутбук: [LR4_marvel.ipynb](LR4_marvel.ipynb). Используются результаты ЛР 3 из `../LR3_marvel/processed/`.

Созданы три признака, числовые признаки стандартизованы с параметрами train, обучен DummyRegressor для двух целевых величин. Метрики и результаты сохранены в `processed/`.

Для запуска в папке ЛР 4 используйте Python 3.12.5, установите пакеты из `requirements.txt` и выполните ячейки ноутбука по порядку.
