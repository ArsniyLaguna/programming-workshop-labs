# Лабораторная работа № 2 — Marvel

Основной файл — [`LR2_marvel.ipynb`](LR2_marvel.ipynb). Работа продолжает [ЛР 1](../LR1_marvel/) и использует именно её сохранённое разделение `614 / 154` из `../LR1_marvel/splits/`. Исходные данные заново не делятся.

## Содержание

1. Сравнение статистической импутации, KNN и случайного леса на искусственно скрытых известных значениях **только обучающей части**.
2. Выбор метода для каждого неполного столбца: лес для трёх геометрических признаков, мода для `Orientation`.
3. Заполнение пропусков в train и test с настройкой методов только на train.
4. One-hot кодирование двух номинальных признаков.
5. Проверка и сохранение результатов в [`processed/`](processed/).

Итог: `X_train` имеет размер `614 × 16`, `X_test` — `154 × 16`; все входы числовые и без пропусков. Целевые файлы переписаны без изменения значений. Метрики импутации и выбранные методы также сохранены в `processed/`.

## Запуск

Требуется Python 3.12.5. Из каталога `LR2_marvel`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab LR2_marvel.ipynb
```

Для Windows команды создания окружения приведены в [README ЛР 1](../LR1_marvel/README.md). Нужна папка `LR1_marvel/splits/` в этом же репозитории. Выполняйте ячейки сверху вниз. При повторном запуске файлы в `processed/` перезаписываются тем же результатом при зафиксированных версиях библиотек.

## Ограничения

Качество импутации измерено маскировкой известных значений и не является оценкой точности будущей модели отопительной и охлаждающей нагрузки. Для `Orientation` лучшая из проверенных стратегий имеет accuracy около 0,22 — пропущенная ориентация остаётся неопределённой. В ЛР 1 использовано случайное разделение строк, поэтому близкие конфигурации могут находиться в обеих частях.
