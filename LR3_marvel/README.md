# Лабораторная работа № 3 — выбросы и аномалии (Marvel)

Основной файл — [LR3_marvel.ipynb](LR3_marvel.ipynb). Работа продолжает ЛР 2 и читает её файлы из `../LR2_marvel/processed/`. Разбиение на обучение и тест не меняется.

## Что сделано

1. Для шести непрерывных входных признаков и двух целевых величин построены гистограммы с границами IQR и ящики с усами. Границы рассчитаны только по обучающей части.
2. Правило Тьюки (`Q1 − 1,5 × IQR`, `Q3 + 1,5 × IQR`) применено к train и test. В данном датасете оно не обнаруживает выбросов.
3. На шести числовых входах после стандартизации применены Isolation Forest и Local Outlier Factor. Их результаты сравнены, а аномальные объекты показаны на проекции PCA.
4. Строки, помеченные обоими методами, проверены по исходным диапазонам и категориям. Это редкие, но допустимые конфигурации без остекления. Обосновано сохранение всех строк. Итоговые train/test записаны в `processed/`.

Аномалия — повод проверить строку, а не доказательство ошибки. Для этих данных автоматическое удаление редких конфигураций ухудшило бы охват допустимых объектов. Тестовые цели не участвовали в поиске аномалий.

## Запуск

Python 3.12.5. Из папки `LR3_marvel`:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab LR3_marvel.ipynb
```

Выполняйте ячейки сверху вниз. Необходимы файлы `LR2_marvel/processed/` в этом же репозитории. Случайное состояние зафиксировано (`42`).
